# MSF-02 Catalog Conformance Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every catalog, delta and MSF URL the publisher emits conforms to MSF-02 by default, with `--msf-version 01` keeping today's bytes.

**Architecture:** `MsfCatalog::version` selects a version profile inside `serialize_catalog()` / validation (`src/msf_catalog.cpp`). Emitters set the version from `PublisherConfig::msf_version`. MSF-02 additions (new fields, required-fields table, `object-property` init data, `update` delta, `cat` URL parameter, uppercase timeline keys) are gated on the profile.

**Tech Stack:** C++20, CMake Unix Makefiles tree in `build/`, Bun for the independent validator script.

**Spec:** `docs/superpowers/specs/2026-11-18-msf02-design.md`; draft text `docs/draft-ietf-moq-msf-02.txt`.

## Global Constraints

- `--msf-version 01|02`, default `02`; `PublisherConfig::msf_version` default `MsfVersion::k02`.
- Catalog `version` strings: `"1"` (MSF-01) and `"draft-02"` (MSF-02).
- `--msf-version 01` output is byte-identical to the pre-change output (compare catalogs with `generatedAt` removed).
- All catalog JSON is produced by `serialize_catalog()`; never hand-assemble JSON.
- Table 6 required fields (02): `loc` audio `codec, bitrate, samplerate, channelConfig`; `loc` video `codec, bitrate, framerate`; `eventtimeline` `eventType`; always `name, packaging, isLive`.
- Namespace: `/`-delimited, 1 to 32 non-empty fields. Track names non-empty. Full Track Name unique.
- initDataList `data` for property entries: `"0x0D"` (video) / `"0x0F"` (audio); VP9 has no `initRef`.
- Delta updates (02): `deltaUpdate` plus `generatedAt` only; ops `add`, `remove`, `update`; `clone` not implemented.
- MSF URL parameter `cat` (was `c4m`); parser accepts both; emitted name follows the version.
- No emoji; no Claude attribution lines in commits. Build in the existing `build/` tree; do not bare-reconfigure cmake.

## Review Focus

- `--msf-version 01` catalogs for CMAF, LOCMAF, LOC and timeline fixtures are byte-identical to the pre-change output.
- A LOC video track from a live source with no measurable frame rate serializes (estimated `framerate`) instead of throwing.
- Namespaces with an empty field, a leading or trailing `/`, or more than 32 fields are rejected under 02.
- `depends` entries that name an unknown track or an unknown `renderGroup` are rejected; a media timeline over a fully covered render group uses the `renderGroup` number only.
- A delta where an attribute is removed (present before, absent after) falls back to an independent catalog, and one that only overrides or adds attributes becomes an `update` op.
